# Author-supplied final media

Add the final presentation at `presentation/FINAL_PRESENTATION.pdf` and the final
course demo at `demo/DEMO.mp4`. No placeholder PDF or MP4 is provided.

The earlier `docs/Presentation.pdf` is a proposal. Existing gameplay under
`reports/` is supporting evidence; neither is automatically substituted for
these final deliverables.

From the project root, `python scripts/build_submission.py --mode draft` builds
an explicitly incomplete draft. `--mode final` requires both actual final files.
See `SUBMISSION_README.md` for installation and submission instructions.
